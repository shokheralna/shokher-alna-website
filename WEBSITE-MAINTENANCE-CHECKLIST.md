# Shokher Alna Website Maintenance Checklist

## Homepage
- Logo loads.
- Hero loads and is properly sized.
- Navigation works.
- Shop/category links work.
- Category automatic images/slideshows work.
- New Arrivals works.
- Best Sellers works.
- Social links work if configured.

## Product pages
- Main image loads.
- Name/category/price are correct.
- Description is correct.
- Thumbnail gallery loads.
- Thumbnail click changes main image.
- Enlarge/lightbox works.
- Next/previous enlarged-image navigation works.
- WhatsApp ordering works when enabled.

## Remember these independent controls

    "featured": true/false
    "bestSeller": true/false
    "newArrival": true/false
    "orderEnabled": true/false

## After editing GitHub
1. Commit changes.
2. Allow GitHub Pages to deploy.
3. Open live website.
4. Hard refresh.
5. Test desktop.
6. Test mobile.
7. Test the changed product/feature.
8. Test at least one individual product page.

Keep these documentation files updated whenever the site's architecture changes.
