SHOKHER ALNA - HOMEPAGE COLLECTION SLIDESHOW

Upload BOTH files to the ROOT of your GitHub repository:

1. script.js
   Replace the existing root script.js

2. style.css
   Replace the existing root style.css

Do NOT change index.html.

How it works:
- Bags card uses main.jpg from visible bag products
- Jewelry uses visible jewelry products
- Sarees uses visible saree products
- Clothing uses visible clothing products
- Handpicked Finds uses visible handpicked-finds products
- Only status "active" or "out-of-stock" is included
- Missing main.jpg files are ignored automatically
- One image = stays still
- Two or more images = soft automatic fade every ~3.8 seconds

To make more images appear in a category slideshow:
- upload that product's main.jpg
- set its status in data/products.js to active or out-of-stock
